# 大肥鱼 🐟 — 我的微信群 AI 伙伴

> 这是我（MIA_Ether）自己在用的微信群机器人。跑在一台 Windows 轻薄本上，服务两个微信群：**广外AI共创** 和 **迈阿醚TML后台**。人设、回复策略、日报内容都是按这两个群的氛围一点点调出来的。

## 它在干什么

- **群聊**：平时潜水，冷场才冒泡；被 @ 立刻回；会自己挑表情包回敬；数学题、联网问题也能答。
- **日报**：每天定时发 AI 资讯（08:30 / 12:30 / 18:30）、赛事（17:00）、财经（19:00）、体育（20:00，仅迈阿醚）、电音（20:30，仅迈阿醚）、笑话（21:00）、话题讨论（21:30），还有早中晚问候。
- **海报**：迈阿醚的日报发图片海报，广外发文字版。
- **私聊**：两个私聊对象有单独的女友人设，自然口语、不卖萌。
- **新人欢迎**：有人进群自动欢迎。

## 人设：永雏塔菲风

第一人称虚拟偶像，高能量、爱演，句尾顺手来个「喵」，开心了就「嘻嘻嘻」，偶尔傲娇一句「坏死了喵～」。管群友叫「雏草姬」。回答先把正确的答案说清楚再卖萌，正事绝不能说错。回话压成一行，一句话一次发完。

完整人设见 [docs/persona.md](docs/persona.md)。

## 我改了什么（跟原版不一样的地方）

这个仓库是在 AstrBot + io-wechat 的基础上，按我的需求改的。核心改动都在微信桥 `dfy_wc_bridge/poller.py` 里：

- **防抖**：同一人连续发的碎片消息先攒成一批再回（安静 2s / 繁忙 5s / 上限 8s），被 @ 的不等，直接回。
- **触发门控**：主动插话不再是固定概率，按内容打分——水消息几乎不回，提问和长消息更愿意回；10 分钟内主动回多了会自动降频、停一停。
- **黑话学习**：每天晚上学群里的新梗，只报新发现，从不自动改人设。
- **联网查询**：被 @ 提问时自己上网搜（Bing），搜不到就老实说搜不到，不编答案。
- **数学触发**：带 `=` 的等式和解方程、求导、积分这些词会触发计算。
- **图片识别**：群里发的单独一张表情/图片，用 Qwen2.5-VL 描述了再回（需要 DashScope Key）。
- **Root 控制**：群里发 `sudo + 命令`，只有我的微信号能用（查状态、调音量、开关早安、重启）。
- **绝不拆句**：一句话必须一条发完，不拆成好几条。

## 怎么跑的

```
云服务器（Muse）→ Tailscale → 轻薄本（Windows）→ 微信 + AstrBot → 两个群
```

- **轻薄本**：`desktop-q8sgthq`，插电永不休眠，微信窗口保持可见，AstrBot 跑在上面。
- **自动同步**：轻薄本每 5 分钟从这个仓库 `git pull`（`dafeiyu-auto-pull`），桥代码变了就自动重启 AstrBot。
- **隧道看门狗**：每 5 分钟检查 Tailscale 隧道通不通，断了就重启 Tailscale 服务（`tailscale_tunnel_check.ps1`）。
- **定时任务**：日报、问候、话题这些都在云服务器上用 cron 调度，通过桥发到群里。

## 安全

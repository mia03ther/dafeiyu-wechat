# 大肥鱼 🐟 — 微信群 AI 伙伴

> 一个跑在 Windows 上的微信群机器人：会主动找你聊天、自己发表情包、每天定时发资讯。基于 AstrBot + io-wechat 改造，人设和回复策略都按群聊氛围调过。

## 它能干什么

- **群聊**：平时潜水，冷场才冒泡；被 @ 立刻回；会自己挑表情包回敬；数学题、联网问题也能答。
- **日报**：每天定时发 AI 资讯、赛事、财经、体育、笑话和话题讨论，还有早中晚问候。所有日报一律发图片海报，不发文字版（电音日报已于 2026-11-22 取消）。
- **新人欢迎**：有人进群自动欢迎。
- **图片识别**：群里发的单独一张表情/图片，用视觉模型描述了再回（需要视觉模型 Key）。

## 人设

第一人称虚拟偶像，高能量、爱演，句尾顺手来个「喵」，开心了就「嘻嘻嘻」，偶尔傲娇一句「坏死了喵～」。说话像直播一样自然，别像背台词。回答问题先把正确的答案说清楚，再卖萌，正事绝不能说错。回话压成一行，简短口语，一句话一次发完。

完整人设见 [docs/persona.md](docs/persona.md)。

## 改了什么（跟原版不一样的地方）

核心改动在微信桥 `dfy_wc_bridge/poller.py` 里：

- **防抖**：同一人连续发的碎片消息先攒成一批再回，被 @ 的不等，直接回。
- **触发门控**：主动插话不再是固定概率，按内容打分——水消息几乎不回，提问和长消息更愿意回；短时间内主动回多了会自动降频、停一停。
- **黑话学习**：每天晚上学群里的新梗，只报新发现，从不自动改人设。
- **联网查询**：被 @ 提问时自己上网搜，搜不到就老实说搜不到，不编答案。
- **数学触发**：等式和解方程、求导、积分这些词会触发计算。
- **绝不拆句**：一句话必须一条发完，不拆成好几条。

## 怎么跑的

```
云服务器 → 内网穿透 → Windows 机器 → 微信 + AstrBot → 微信群
```

- **部署**：跑在一台常开的 Windows 机器上，微信窗口保持可见，AstrBot 跑在上面。
- **自动同步**：机器每 5 分钟从这个仓库拉取更新，桥代码变了就自动重启 AstrBot。
- **隧道看门狗**：定期检查内网隧道通不通，断了就重启隧道服务（`tailscale_tunnel_check.ps1`）。

**本仓库不包含任何真实 Token、密钥、账号或聊天记录。** 密钥只放本地（`.env`、`api_keys.json`、`cmd_config.json` 都在 `.gitignore` 里），首次运行需自行登录生成。
